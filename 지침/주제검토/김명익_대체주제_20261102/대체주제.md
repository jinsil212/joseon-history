# 김명익 집안 귀신 사건 → 더 후킹되는 대체 주제 (2026-11-02)

원안: ① 「숙종실록 김명익 집안 사건, 귀신 이야기 뒤에 어떤 조사와 처벌이 있었을까」
사용자 요청: "관련 더 후킹되는 주제로 치환".

원안이 약한 이유(작업자 해석): 김명익은 시청자가 모르는 이름이다. 기존 선택 기록(수정·선택 사례.md — 을사오적·만원권 세종·「내 합격이 취소됐다」)처럼 **누구나 아는 대상**이나 **자기 대입**이 없다. 「귀신 → 조사·처벌」 축은 살리고 입구를 바꾼다.
확인 한계: 이 세션에서는 실록 사이트에 접속할 수 없어 김명익 기사 원문은 확인하지 못했다. 아래 사실도 원고 전 실록 원문 대조가 필요하다.

## 추천 ① 장희빈 저주 사건(1701, 무고의 옥) — 「누가 찾아내고 누구까지 벌했나」 수사편

- 입구: 드라마로 모두 아는 장희빈. 「인현왕후를 저주했다」는 결말만 알고, **어떻게 드러났고 어떻게 조사·처벌했는지**는 잘 모른다 → 원안의 「귀신 뒤의 조사와 처벌」 축을 그대로 옮김.
- 뼈대(원문 확인 필요): 1701년 8월 인현왕후 승하 → 9월 숙빈 최씨가 숙종에게 알림(숙종실록 27년 9월 기사로 알려짐) → 취선당 서쪽 신당, 무녀를 불러 굿·기도 → 궁녀·무녀 국문 → 장희재 처형, 무녀 등 처형, 10월 희빈 자진 → 「빈을 후비로 올리지 못한다」는 법 제정.
- 채널 조건: 모두 아는 대상 ○ / 권력자도 당했나 ○(왕비·희빈) / 수사 절차(파주탄막_도적처럼 「사건 처리 절차를 뼈대로」) ○
- 겹침: `원고/인현왕후`(저주 언급 1~2문장), `원고/영조_숙빈최씨`(고변 장면). 수사·처벌 절차 중심으로 쓰면 겹침 적음. 발행 간격 권장.

제목 가안
1. 「장희빈의 인현왕후 저주, 궁궐 안 신당은 누가 찾아냈고 누구까지 벌을 받았을까」
2. 「왕비를 저주한 신당이 궁궐에 있었다, 숙종은 장희빈 사건을 어떻게 조사했을까」

썸네일(2줄)
- A(추천): 「궁궐 안 저주 신당 / 누가 찾아냈을까?」
- B: 「장희빈 저주 사건 / 벌 받은 사람은 몇 명?」 (처벌 인원 원문 확정 후에만)
- C: 「장희빈만 죽은 게 / 아니었다?」

## 대안 ② 여환 미륵 역모(1688, 숙종 14년)

- 「큰비가 오면 한양이 무너지고 미륵의 세상이 온다」는 예언을 믿고 양주 일대 승려·무당 무리가 도성에 들어가려 했던 사건. 예언 → 고발 → 국문 → 처형까지 「믿음 뒤의 조사와 처벌」.
- 제목 가안: 「"큰비 오면 한양이 무너진다" 숙종 때 무당의 예언을 믿은 사람들은 어떻게 됐을까」
- 썸네일: 「무당 예언 믿고 / 한양을 노렸다?」
- 약점: 인물이 낯섦. 예언·「비 오는 날」 장면이 강해 입구는 된다. 날짜·인원·예언 문구는 실록 원문 확인 필요.

## 대안 ③ 원안 보강형 — 「조선 양반집 귀신 소동, 실록은 범인을 찾았다」

- 김명익 사건 하나 대신 실록 속 집 귀신 소동 여러 건(예: 성종 17년 정창손 집 귀신 이야기로 알려진 기사)을 「귀신 소문 → 나라가 조사 → 사람이 한 짓」 구조로 묶는다.
- 썸네일: 「양반집 귀신 소동 / 범인은 사람이었다?」
- 조건: 각 사건에 실제로 「사람이 한 짓」 결론이 실록에 있을 때만. 없으면 이 썸네일은 쓰지 않는다.
