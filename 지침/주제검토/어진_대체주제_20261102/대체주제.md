# 철종 초상 소재 → 대체 주제 (2026-11-02)

사용자 반려: ① 「조선 철종의 초상화, 불탄 자국은 언제 어디서 생겼을까」 — "너무 세부적이어서 애매해, 더 후킹되는 다른 주제로".
반려 이유(작업자 해석): 철종 한 점·불탄 자국 하나는 시청자가 이미 궁금해하던 대상이 아니다. 기존 선택 기록(수정·선택 사례.md)처럼 **누구나 아는 연결어 + 현대 대응물**이 없다.

## 추천 대체 ① 만원권 세종 얼굴 → 조선 왕 얼굴이 거의 안 남은 이유

- 입구: 지갑 속 만 원짜리 세종 얼굴(모두가 아는 대상, 현대 대응물). 1973년 김기창이 그린 **상상 초상(표준영정)** — 세종의 실제 어진은 남아 있지 않다.
- 질문: 왕마다 화원이 그려 모신 어진은 다 어디로 갔나. → 어진 제작 절차(도사·추사, 왕이 닮았는지 품평) → 전쟁 때 옮겨 다닌 길 → 1954년 12월 부산 용두산 화재(보관 어진 48점 중 30점 완전 소실, 18점 훼손 회수 — 위키백과, 원문 재확인 필요) → 철종 어진의 불탄 자국은 이 결말의 한 장면으로만.
- 채널 조건(사례 파일 네 조건): 현대 대응물 ○(지폐) / 권력자도 당했나 ○(왕의 얼굴조차 사라짐) / 1950년대 피란 기억 ○ / 신체 감각 △
- 겹침: 기존 원고에 어진 편 없음. `원고/철종`과는 계승 과정 편이라 소재 겹침 없음.

| 구분 | 적용 |

| H 사건 요약 | 왕마다 그려 모신 조선 어진 / 전쟁과 1954년 화재로 대부분 사라졌다 |

## 대안 ② 조선 사람 평균 키
「조선 남자 평균 키는 몇이었을까, 뼈와 기록으로 본 조선 사람의 몸」 / 썸네일 「조선 남자 평균 키 / 지금보다 얼마나 작았을까?」 — 신체 감각·현대 대응물 ○. 유골 연구 수치는 논문 원문 확인 전(숫자 미기재).

## 대안 ③ 왕의 얼굴을 그리는 날(어진 제작 자체)
①보다 좁다. ①의 본문 한 장으로 쓰는 것을 권함.
