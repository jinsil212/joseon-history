# 조선 역사 — 벤치마크 채널 현황과 신규 후보 조사 (2026-10-10)

사용자 요청: 지금까지 벤치마킹한 한국 채널과 원문을 본 채널 확인 + 같은 주제로 성과가 좋은 작은 한국 채널 조사.

조사 방법: 로컬 보관 자료(`분석지/`, longform-studio `joseon-history/config/_benchmarks*`) 확인 + yt-dlp로 유튜브 검색 6개 질의 × 25건(총 150편, 채널 50개)에서 후보를 뽑아 채널별 최근 15편의 조회수·구독자를 직접 조회. 구독자는 유튜브 표시값(반올림), 조회수는 2026-10-10 시점 누적값이다. 게시 당시 구독자·노출·클릭률·유지율은 확보하지 못했으므로 성과의 원인은 확정하지 않는다.

## 2. 주제 중복 경고 — 원경왕후

- 한밤의 한국사, 2026-09-04, 「태종 이방원이 킹메이커 원경왕후를 배신하고 후궁을 17명이나 거느린 진짜 이유」 16,927회. 주채널 최근 중앙값(42,000)보다 낮다.
- 같은 채널 2026-08-29 「이성계가 죽기만을 기다린 이방원의 잔인한 복수…조선 최초의 왕비」 71,765회.
- 조선왕조실록이야기 2026-08-28 「시아버지가 친정을 몰살했는데 쫓겨나지 않은 진짜 이유」(소헌왕후) 7,221회.
- 판단: 우리 원경왕후 편은 주채널이 한 달 전에 다룬 소재다. 다만 그쪽은 후궁 17명을 전면에 세웠고 성과도 평소보다 낮았다. 우리 기획(공이 경계의 이유가 된 과정, 네 형제)과 포장이 겹치지 않는지 제목 확정 전에 대조한다. 조회수 차이를 포장의 인과로 결론내지 않는다.

## 4. 적용 제안 (작업자 의견, 확정 아님)

- 15분 미드폼 길이의 견본으로는 **알zip사**가 가장 가깝다. 생활사 소재 + 짧은 길이 + 구독 대비 성과가 함께 확인된다. 분석지 006으로 추가 검토 대상.
- 장편 전환을 검토한다면 **진짜역사한잔**, 인물 서사 변주는 **역사탐사실**이 후보다.
- 역사비는 성과가 높아 보여도 모방 정황이 있어 구조 견본에서 제외한다.
- 실제 채택 전에는 공용 P0-2에 따라 원문 전문과 썸네일을 확인하고 분석지를 작성한다. 이번 조사는 목록·수치 확인까지다.
