## 1. 주제 고르는 기준 (가장 중요)

**통과해야 할 질문: "시청자가 '나였으면?' 하고 몸으로 느끼나?"**

조회수 높은 주제는 모두 **사람의 몸이 겪는 기본 조건**을 건드린다.
- 잠: 주막(모르는 사람 열 명과 한 방)
- 추위: 조선의 겨울
- 시험·취업: 과거시험(10년 낙방, 밭 팔아 노잣돈)
- 들키면 끝나는 잠입: 암행어사
- 발밑의 숨은 세계: 독도와 남해(물을 빼면 보이는 산과 땅)
- 매일 먹는 것의 원리: 김치

하위권은 **남의 이야기를 구경하는 주제**였다. 화가의 그림(금강산), 물건의 내력(짚신), 학설 바로잡기(대동여지도).

### 주제 체크리스트
- [ ] 서민(또는 왕까지) 누구나 겪은 **하루, 하룻밤, 한 계절, 한 번의 길**인가
- [ ] 제목에 **역설이나 극한** 한 줄을 만들 수 있나 (공짜인데 목숨, 왕인데 생지옥)
- [ ] 실록·승정원일기·개인 일기·외국인 여행기에 **날짜가 박힌 사건이 5개 이상** 있나
- [ ] 지금 우리 일상과 이어지는 **"그래서 지금 ○○이 이렇다"** 결론이 있나 (찜질방, 국밥, 수능 엿, 인덕원)
- [ ] 장면마다 **3D로 보여 줄 장소**가 있나 (마당, 방 안, 고개, 성벽, 얼어붙은 강)

### 제목 공식
`[역설·극한 한 줄] | [근거 표시 부제]`
- 조선 주막 방값은 공짜, 대신 목숨을 걸었다 | 승정원일기·실록으로 본 조선 주막
- 조선의 겨울, 왕에게도 생지옥이었다 | 실록으로 본 조선의 겨울
- 조선 극한직업, 암행어사의 생존 길찾기 | 지도 없이 걸은 65일, 실제 일기로
- 지리형: `[물/땅을 걷어내면 보이는 것] | [몇 만 년 전 ~]` (남해 바닷물을 다 빼면 나오는 것)

## 3. 도입부 유형 4가지 (상위권은 모두 첫 문장에 장면이 있다)

1. **실록 사건 충격형**: 연도 → 장소 → 사망·피해 숫자 → 기록 한 줄 인용 → 반전 (주막, 겨울)
2. **인물 위기 시네마형**: 날짜와 시각 → 날씨 → 인물의 나이·처지 → "이번에도 떨어지면 돌아갈 곳이 없습니다" (과거시험, 암행어사)
3. **상식 뒤집기형**: "누구나 이렇게 생각합니다 … 아니었습니다" + 놀라운 숫자 (독도: 바위섬 → 2,068m 산, 한라산보다 높다)
4. **사고실험형**: "~에 거대한 마개가 있다고 상상해 보겠습니다" → 10m, 50m, 120m 단계별로 공개 (남해, 독도)

## 4. 하위권 도입부의 문제 (피할 것)

- **금강산**: 화가 정선에서 시작했다가 "답을 찾으려면 60년 먼저 길을 나선 청년부터" 하고 **두 번 돌아간다.** 주인공이 늦게 나오고 시청자가 겪을 위험이 없다.
- **착호갑사**: 도입은 강하지만 역시 "답을 찾으려면 ~부터 따라가 봐야 합니다"로 미룬다.
- **짚신**: 감동적인 사연(원이 엄마 편지)이지만 주제가 **물건**이라 "나였다면?"이 생기지 않는다.
- **대동여지도**: 교과서 바로잡기, 학설 검증. 지적 흥미는 있지만 몸으로 느낄 위험이 없다.

→ **규칙:** 30초 안에 주인공(또는 "당신")이 겪는 위험과 큰 질문을 다 보여 준다. "그 답을 찾으려면 ~부터"로 미루지 않는다.

## 5. 본론 한 덩어리 쓰는 법 (5단 반복)

```
[연도+장소+출처]  1733년 전라도 남원, 관아 벽에 … (영조실록)
[감각 장면]       사립문을 밀면 먼저 소리와 냄새가 덮칩니다. 귀를 묶어 둔 검은 돼지…
[의외의 사실]     방값은 받지 않는다.
[현대 비유]       오늘날 작은 욕실만 한 방 / 지금의 휴게소와 여인숙을 합친 셈
[다리 질문]       그런데 이 방에서 가장 무서운 건 좁은 자리가 아니었습니다.
```

### 다리 문장 패턴 (덩어리 끝마다)
- "그런데 ~은 처음부터 ~였던 건 아닙니다."
- "그렇다면 ~은 어땠을까요?"
- "~이 이 정도였다면, ~은 어땠을까요?" ← 겨울 편의 **규모 사다리**: 왕 → 궁녀 → 숙직 군사 → 길 위 → 백성 → 나라 전체(남한산성) → 기후(소빙기) → 대기근
- "위험은 ~만이 아니었습니다."
- "그렇다고 ~이 늘 ~하기만 했던 건 아닙니다." (정서 반전으로 넘어갈 때)

### 숫자 쓰는 법
- 큰 숫자는 몸에 와닿는 비유로 바꾼다: 2.4×1.8m는 작은 욕실, 120m는 롯데월드타워 절반, 하루 100리는 약 40km
- 숫자는 단계적으로 공개한다: 10m → 50m → 120m / 27℃ → 33℃ → 40℃
- 한 덩어리에 핵심 숫자는 1~2개만

### 출처 섞기 (신뢰를 주는 장치)
실록·승정원일기(나라의 기록) + 개인 일기(노상추일기, 박만정 『해서암행일기』) + 외국인 여행기(비숍, 게일) + 지금 남은 장소와 유물(삼강주막, 서빙고). 학설이 갈리면 "~라는 가설입니다", "~로 봅니다"라고 단정하지 않는다.

## 6. 문체

- 기본은 합니다체. 문장은 짧게 (한 문장 15~35자 정도).
- 정리할 때: "~였던 겁니다", "~인 셈이죠", "~했던 거죠"
- 인용은 짧게 직접 인용: "손님은 죽었는데 주인은 다치지 않았다. 이 또한 의심스럽다."
- 인물 여정형은 "~어요"를 섞어 친근하게 써도 된다 (암행어사 편).
- 3D 화면을 염두에 두고 **눈에 보이는 장면 문장**을 덩어리마다 1개 이상 넣는다. 그 문장이 그대로 영상 프롬프트의 재료가 된다.

## 7. 3D 화면과 맞물리는 대본 표시

대본을 쓸 때 문장 옆에 화면 종류를 같이 적어 두면 프롬프트 만들기가 쉽다.

| 표시 | 화면 | 쓰는 곳 |
|---|---|---|
| [3D] | AI 3D 디오라마 영상 (8초) | 감각 장면, 인물 행동 |
| [지도] | 위성지도 줌 + 경로선 + 지명 점 | "1780년 경상도 선산", 이동 |
| [기록] | 노란 종이 인용 카드 (출처·날짜) | 실록 인용 |
| [숫자] | 큰 숫자 카드 (100리, 27℃) | 핵심 숫자 |
| [목록] | 체크리스트 카드 | 여러 항목을 정리할 때(약속 목록 용도는 폐지) |
| [연표] | 가로 타임라인 | 사라진 이유, 정리 구간 |
| [질문] | 큰 문구 ("당신이라면 어디에?") | 큰 질문 문구(투표·대입 질문 용도는 폐지) |

비율 참고(주막 편): 3D 약 75%, 지도 약 8%, 카드류 약 17%. 화면 전환은 평균 7~8초.
