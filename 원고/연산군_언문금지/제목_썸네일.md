# 연산군_언문금지 — 제목·썸네일 후보 (2026-11-02)

주제: 연산군은 왜 한글을 금지했을까 — 한글 익명 투서 사건과 추적 절차

## 형식 근거(T0, 작업자 해석)
사용자 확정 기록에서: 제목은 「~없던 조선, 질문」(호텔·네비·치과) 또는 「대상·상황, 질문」(늙은궁녀·장한철), 현대 말로 자기 대입(퇴직·네비). 썸네일은 2줄, 한 줄은 아는 대상, 다른 줄은 질문·역설(「궁 나가면 어디서 살지?」「밥값만 내면 잠은 공짜」).

## 제목 후보
1. 한글로 쓴 익명 투서 한 장, 연산군은 왜 한글을 금지했을까 — 대상·상황, 질문
2. 연산군을 욕한 한글 투서, 범인을 찾으려고 무엇까지 했을까 — 사건 처리 절차 중심(파주탄막 「보고에는 범인 얘기가 없었다?」 계열). 범인을 잡았다고 암시하지 않음
3. 백성이 쓰던 글자를 왕이 막았다, 연산군의 한글 금지령은 왜 나왔을까 — 역설 + 질문

## 썸네일 후보 (2줄)

B. 한글 아는 사람 / 전부 신고하라 — 극단 조치 인용형. 연산군일기 10년 7월 원문 확인 후에만 사용
