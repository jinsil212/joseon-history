# 어진_왕의얼굴 — 제목·썸네일

## 출발점 (사용자 원안, 2026-11-02)
- 제목: 조선 태조·영조의 얼굴, 왕이 죽은 뒤 그린 초상화를 믿어도 될까
- 썸네일: 조선 왕이 죽은 뒤 그린 초상 / 화가는 뭘 보고 그렸을까?
- 사용자 질문: “이거 후킹되는 주제 같아?”

## 작업자 검토
- 전제 오류: 현존 태조 어진(경기전)은 1872년 조중묵·백은배·박기준 등이 태종 대 모사본을 다시 모사한 것, 현존 영조 어진은 1900년 경운궁 선원전 화재 뒤 조석진·채용신이 51세 때 생전 어진을 모사한 것 → 「죽은 뒤 상상으로 그림」이 아니라 「생전 초상을 베낌」. 썸네일 질문의 답이 기대를 무너뜨림(채널설정: 실제 내용과 다른 기대 금지).
- 채널 4조건(채널설정 2026-09-17): 신체 감각 약함 / 현대 대응물 있음(사진 보정·몽타주) / 노년층 증언 없음 / 권력자 반쯤(왕이 주인공).
- 대안 3안 제시: 1) 점 하나도 감추지 않은 어진 2) 얼굴이 남은 왕은 몇 명뿐 3) 원안 살려 「언제 누가 다시 그렸나」. 작업자 추천 1.

## 사용자 선택 (2026-11-02, 발언 “1”)
- **제목(확정)**: 조선 왕의 초상화는 점 하나도 감추지 않았다, 지금 남은 왕의 얼굴은 진짜일까
- **썸네일(선택안)**: 왕 얼굴의 검버섯까지 / 그대로 그린 조선 화가
- 선택 뒤 사실 확인 결과:
  - 「털끝 하나라도 실제와 다르면 안 된다」는 조선 초상화 원칙, 태조 어진 **오른쪽 눈썹 위 사마귀** 표현 — 전주 어진박물관 전시 소개(전북일보 2019-05-24)로 확인. 단 현존본은 1872년 재모사본이라 원본 단계 표현인지는 본문에서 「모사본에도 남아 있다」 수준으로 말한다.
  - 어진의 **검버섯** 표현은 출처를 찾지 못함 → 썸네일 「검버섯」은 사실 확인 전까지 쓰지 않는다. 교체안 「왕 얼굴의 사마귀까지 / 그대로 그린 조선 화가」를 사용자에게 확인 요청(대기).
  - 부산 피란 중 화재로 어진 대부분 소실, 연잉군 초상·철종 어진 일부 탐 — 확인. 화재 연도(1954)는 별도 출처 필요.

## 썸네일 확정 (2026-11-02, 사용자 “사마귀가 맞다면 그렇게 가”)
- **썸네일(확정)**: 왕 얼굴의 사마귀까지 / 그대로 그린 조선 화가 — 태조 어진 오른쪽 눈썹 위 사마귀(S1) 확인 뒤 교체
