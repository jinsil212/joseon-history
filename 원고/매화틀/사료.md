## 확인했으나 쓰지 않은 것 / 확인 못 한 것

- "복이나인이 매화틀을 들고 내의원으로 가고, 내의원(또는 전의감)이 배설물의 냄새와 맛으로 건강을 살폈다": 2012 경향(이기환)·검색 요약의 신문 기사에만 있고 조선 시대 원문 기록을 찾지 못함. 내의원/전의감도 기사마다 다름 → 대본에서는 "흔히 그렇게 전해지지만, 이 장면을 적은 조선 시대 기록은 찾기 어렵다"로 성격을 밝히고, 실제 기록(M1)으로 대신함.
- "매추"(그릇 안에 잘게 썬 여물): 개인 카페 글 단일 출처 → 쓰지 않음.
- "궁궐지에 경복궁 뒷간 28개": 검색 요약에만 있고 출처 페이지를 열지 못함 → 쓰지 않음(M6의 75.5칸만).
