## 확인 못 한 것 · 쓰지 않은 것

- ‘대비정속(代婢定屬): 늙은 기생이 딸·조카딸을 대신 넣고 나옴’ — 신문 기사 수준 설명만 확인. 용어는 쓰지 않고, 박영민 논문의 실제 기록(G6·G8·G9)으로만 대신 들이는 관행을 말함.
- 퇴기가 기방·주막을 차렸다는 이야기 — 학술 근거 미확보(005 주막 견본의 주장도 사실 출처 아님) → 쓰지 않음. 퇴기가 어린 기생을 가르쳤다는 설명은 위키·국가유산청 개괄 수준 → 쓰지 않음.
- 계섬(심노숭 「계섬전」)의 노년 — 원문·번역 미확인 → 쓰지 않음.
- 홍랑과 최경창의 관계 — 실록은 관비 이름을 적지 않음 → 이름 없이 G12만.
- 명선(『소수록』) — 해설서 수준 확인, 성적 묘사 위험(S14) → 이번 대본에서 제외.
- 1431년 기생 신분 세습 율 결정 — 신문 기사 수준 → 쓰지 않고 G10(1437 수교 언급)으로 대신.
- 승천금의 이후 삶, 천종의 아버지 — 미확인.

## 낭독 표기 메모

- 천종, 승천금, 해단, 남산옥·분단, 추향월·호매, 김인겸, 이자문, 최경창.
- ‘노제(老除)’ 용어는 낭독에서 쓰지 않고 “늙어서 명부에서 빼 주는 것”으로.
- ‘역(役)’은 “기생 일/관청 일”로. ‘속신’은 “몸값을 치르고 풀려나는 것”으로 먼저 풀고 이름은 한 번만.
