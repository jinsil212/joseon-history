## 확인 못 한 것 · 쓰지 않은 것

- 박문규가 젊어서부터 과거에 여러 번 응시·낙방했는지: **확인 못 함**. 대본에서 그를 ‘평생 과거만 본 사람’으로 말하지 않는다. ‘여든셋에 별시에서 급제한 사람’으로만 쓴다.
- 박문규가 ‘조선 최고령 급제자’인지: 확인 못 함 → 최상급 표현을 쓰지 않는다.
- 1800년 경과 정시의 최종 급제 인원(언론은 10명): 실록 해당 기사 미확인 → 쓰지 않고, 정시 정원 성격(10명 이하, F4)만 말한다.
- 황윤석 26회 각 시험의 날짜·답안 내용·낙방 때의 감정 문장: 논문 본문 미열람 → 지어내지 않는다. 일기에 남은 확인 사실(F6·F8)만.
- 『이재난고』 기사의 ‘53세까지’ 표기는 생몰년(1729~1791)과 어긋나 쓰지 않음.
- 조선 전체 문과 시행 횟수·급제자 총수: 카페 글뿐 → 쓰지 않음.
- 정약용 『경세유표』의 대리시험 6인조: 이번 핵심(왜 그만두지 못했나)과 무관 → 제외.
