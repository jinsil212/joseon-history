## 확인 못 한 것 · 쓰지 않은 것

- 『경국대전』에 내시 입양만 따로 정한 조문: 확인 못 함 → 대본에서 법조문을 말하지 않음. 우리역사넷의 ‘세 살 이전 입양 허락’도 대본에 쓰지 않음.
- 『연려실기술』의 내시 아내 간통 처벌 대목: 원문 미확인(언론 기사 전언뿐) → 쓰지 않음.
- 양반 딸이 내시와 혼인한 ‘이유’(생활고·왕실 연줄 등): 언론 기사 해석뿐 → 대본에서는 “기록은 이유를 적지 않았다”로 쓰고, 확인된 재산·칭호만 말함.
- 나업 부부의 혼인 연도, 한씨의 생몰년: 미확인.
- ~~나업의 네 양자가 모두 내시였는지: 미확인~~ → **2026-10-12 이어받은 세션에서 확인(◐):** 서울역사박물관 해설 원문(`...&sso=ok` 주소로 열람) “부부 사이에 자식이 없어 고자인 아이 네 명을 양자로 들였다”, “아버지와 성이 다르지만 나업의 족보에 올라 있다”. 대본 4장에서 “네 아들도 어린 내시였다”로 사용. 같은 해설에서 F4(1596년 나언기·평산 김씨 사이 출생, 17세 입사, 25세 승전색, 장릉 3년, 노비 4구·30결, 인조 승하 때 침전을 지킴)·F5(문철이 어머니 뜻을 받아 적음, 인장 문구, 4장 작성, 봉산 서남면 몰수 전답)·F6(속초 보광사 목조지장보살좌상 발원문)을 재확인. 최언순은 선조를 의주까지 호종해 호성공신.
- F1 실록 기사(연산 2년 2월 2일)는 이번 세션에서 다시 열어 “宮禁之事, 宦寺掌之”로 시작하는 본문과 오촌·사천 금지, 잔읍 관노 처벌을 재확인.
- 중국(명) 환관의 혼인 여부 비교: Bernard 영상 미시청, 확인 안 함 → 비교 문장 쓰지 않음.
- 한효원 발언 뒤 실제 금지 조치: 이 기사에는 왕의 답이 없음 → “그 뒤에도 내시의 혼인은 이어졌다”는 운림고택(F9)·나업(F5)으로만 말함.

## 낭독 표기 메모

- 나업(羅嶪), 최언순, 한기, 남궁식·정역·문철·주빈, 김두상, 김일준, 김규석.
- ‘성(姓)’은 문맥상 ‘성씨’와 섞어 써서 ‘성(城)’과 헷갈리지 않게 함.
- ‘30결’ 같은 토지 단위는 낭독에서 쓰지 않음(“넓은 땅”).
