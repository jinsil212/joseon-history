# 주막_잠자리 — 제목·썸네일 검토 (대본 v3 기준, 2026-11-01)

사용자 요청: 「조선의 숙박 시설에 대한 이야기를 서양인들이 남긴 걸 토대로 … 제목이랑 썸네일이 기존 거랑 좀 달라질 수 있을 것 같은데, 가장 fit한 게 뭐가 될 수 있을지 자세히 체크」

## 검토 기준

1. **v3가 실제로 답하는 질문**: ① 조선 주막의 잠자리는 어떤 자리였나(밥값에 딸린 봉놋방) ② 그게 싫으면 어디서 잤나(객사·역관, 객주·여각, 아는 집, 절) ③ 그 이야기를 누가 남겼나(서양인들의 기록)
2. **사용자 과거 선택(수정·선택 사례.md)**: 「현대 대응물이 없던 조선, 질문」 꼴(치과가 없던 조선 / 큰 강에 다리가 없던 조선), 썸네일 2줄 = 아는 대상 한 줄 + 궁금증 한 줄, 현대어로 자기 대입(퇴직, 숙박 포함 식사, 380KM)
3. **채널 성과 조건(채널설정.md)**: 몸으로 느끼는가(한방 열 명·뜨거운 바닥), 현대 대응물(호텔·게스트하우스)
4. **자기잠식**: 한양성문(「못 들어간 사람은 어디서 잤을까」), 과거길(「어디서 먹고 자며 갔을까?」)과 같은 질문 꼴을 피함. 원본 영상 제목 「조선 주막 방값은 공짜, 대신 목숨을 걸었다」와 같은 문장은 쓰지 않음
5. **도입과 맞물림**: v3 콜드오픈(방값 없는 주막 → 비숍의 100푼 → 숙박 포함 식사 → 「먼 길을 가던 사람들은 밤마다 어떤 방에 누웠을까요? 그 방이 싫으면 어디로?」)

## 후보

### ⭐ 1안 (추천)
- 제목: **호텔이 없던 조선, 먼 길 가던 사람들은 밤마다 어떤 방에 누웠을까 | 서양인들이 남긴 조선의 숙소 기록**
- 썸네일: **밥값만 내면 잠은 공짜 / 서양인이 묵어 본 조선 주막**
- 맞는 점: 제목의 질문이 v3 전체(주막 + 주막 밖 숙소)를 덮고, 대본 첫 질문 문장과 같은 말이라 도입이 바로 이어받음. 부제가 「서양인 기록」 틀을 미리 알려 ②와 뒤쪽 외국인 이야기의 이유가 됨. 썸네일 1줄은 원본 100만 영상이 끈 「방값 공짜」 역설, 2줄은 이번 편만의 각도(서양인의 눈). 콜드오픈 1~4줄(방값 없음 → 비숍 100푼 → 숙박 포함 식사)이 바로 회수
- 주의: 「밥값만 내면 잠은 공짜」는 ① 「밥값 안에 잠자리가 들어 있었기 때문」, ⑤ 「잠자리와 마구간은 덤」으로 사실 뒷받침. 원본 제목과 소재 표현(공짜)이 겹치지만 문장은 다름

### 2안
- 제목: **서양인이 묵어 본 조선 주막, 열 명이 한 방에서 자야 했던 이유? | 1880~1900년대 여행기로 본 조선의 숙소**
- 썸네일: **방값은 공짜인데 / 열 명이 한 방에서?**
- 맞는 점: 몸 감각(한방 열 명)이 가장 세고, 대상(서양인·주막)을 앞에 둔 질문형 — 사용자가 고쳐 쓴 꼴(대상 앞, 「~이유?」)과 같음
- 약한 점: v3의 ⑪(객사·객주·아는 집·절, 약 3분)이 제목 약속 밖. 「이유」의 답(밥값에 딸린 잠자리·내외)은 ⑤에 있지만 짧음

### 3안 (기존 F열 유지)
- 제목: 밥 먹으면 방값이 따로 없던 조선 주막, 실제 잠자리는 어땠을까
- 썸네일: 조선 주막의 ‘숙박 포함 식사’ / 밥값에 잠자리가 딸려왔다
- 맞는 점: 사용자가 이미 확정한 문구, 콜드오픈과 완전히 맞음
- 약한 점: v3의 두 축(서양인 기록, 주막 밖 숙소)이 제목에 없어 ②(1분 20초)와 ⑪(3분)이 곁가지로 보일 수 있음. v2(주막 중심, 약 9분)에는 가장 잘 맞았던 문구

## 버린 후보와 이유
- 「조선에 온 서양인들 / 주막 방문을 열었더니」 — 무엇을 봤는지 없는 맥락 없는 반응(반려 경향)
