# 정순왕후(영조 계비) — 사료 (사실 / 출처 / 원문 핵심 / 대본 사용 위치)

확인일 2026-10-12. 이날 오후 조선왕조실록 사이트(sillok.history.go.kr) 접속이 계속 거부되어(ECONNREFUSED) 순조실록 원문 직접 대조는 하지 못했다. 그 대신 한국민족문화대백과(학술 집필 항목)·학술 논문·복수 언론 기사로 교차 확인했고, 확인 수준이 낮은 세부(날짜 일·구체 발언)는 대본에 쓰지 않았다. 유튜브 견본(조선왕조실록이야기 1탄)의 주장은 사실 출처로 쓰지 않았다.
