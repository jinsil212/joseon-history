# 부북일기 — 사료

확인일 2026-10-12. 일기 원문(울산박물관 영인본)·우인수 역주서(2012)는 직접 열람하지 못했다. 아래 날짜별 일기 구절은 **정시열 논문이 영인본에서 입력해 각주에 실은 한문 원문과 번역**(우인수 역주 참고)으로 확인했다. 유튜브 견본(역사한줄·역사아카이브)의 주장은 사실 출처로 쓰지 않았다(자막 미확보).

## 쓰지 않는 것 / 주의

- 기생 관련: 방직기 제도는 한 문장, 월매는 기록이 확인하는 범위(찾아옴·확인·떠날 때까지 가깝게 지냄)만. 아버지 추정은 「연구자는 짐작」으로 성격을 밝힘. 태옥에게 광대 옷 입혀 춤추게 한 대목은 선정적 소비 우려로 제외.
- 「1645년 기록」 같은 단일 연도 혼동 주의: 아들 출발 1644.12, 회령 근무 1645, 귀향 1646.4.
- 회령 도착 날짜·근무지 변경 경로(회령→병영) 세부는 미확인 → 「병영」「회령」 정도로만.
- 조총 제작지는 병마절도사 병영(함경북도 병영)으로 추정되나 원문 미확인 → 「병영」이라고만 씀.
