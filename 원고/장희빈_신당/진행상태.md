## 점검(사용자 지시 항목)
| 점검 | 결과 | 실제 구절 |
|---|---|---|
| 도입이 클릭 이유를 받음 | 통과 | ① 비망기의 「취선당 서쪽에 몰래 신당」 → 「원래대로라면」(유학의 나라, 굿은 단속) → 「그 신당 안에는 무엇이 있었고, 무엇을 빌었던 걸까요?」 |
| 다음을 듣게 만드는 고리 | 통과 | ① 끝 「전혀 다른 두 이야기」 → ⑧에서 회수. ④ 「조사가 시작되기도 전에 처분부터」 → ⑧에서 다시 씀. ⑤ 「귀신 들린 집 같은 답」 → 「하지만 숙종은 끝내지 않았다」 → ⑥ 자백 |
| 썸네일 「신당엔 뭐가 있었을까?」 회수 | 통과 | ⑤ 기도 때 바친 물건, ⑥ 각시 인형과 참새·쥐 뼛가루(대조전·통명전 주변), ⑪ 정리 |
| 제목 「그 안에서는 무슨 일」 회수 | 통과 | ① 몸종 두세 명과 사람을 물린 기도, ⑥ 자백(왕비 죽음·복위 기원), ⑧ 다른 진술(세자 두창 쾌유 기원) |
| 몰랐던 사실 | 통과 | 처분이 조사보다 먼저 나옴(④), 「집이 저절로 울렸다」는 첫 진술(⑤), 1699년 두창 신당설(⑧), 명성왕후의 전례(⑧), 사약이 아니라 자진(⑩), 후궁 왕비 금지법과 인원왕후 간택(⑪) |
| 고발자 비중 | 사용자 지시대로 축소 | ③ 두 문장만 |
| 반복·사족 | 정리함 | 「열흘 사이」 오류(실제 보름) 수정, ⑧의 「처분이 먼저」는 ④를 되풀이하지 않고 한 문장으로만 회수, ④의 「세자를 생각해 달라」는 ⑨에만 남김, ⑥ 끝의 썸네일 언급 메타 문장 삭제, ③의 근거 없는 병세 묘사 삭제 |
| 유튜브 정책 | 확인 | 고문은 「매를 치며 묻는 방식」 한 문장, 처형·자진은 사실만. 사약 장면 묘사 없음 |
| TTS 표기 | 확인 | 낭독문에 가운뎃점 없음, 연도 아라비아 숫자 |
