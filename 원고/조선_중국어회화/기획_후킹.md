# 조선 중국어 회화 — 후킹 기획 디벨롭 (2026-11-02)

## 출발점 (사용자 제공 ①)
- 주제: 한문 읽던 조선 사람들, 중국어로 말하려면 무엇을 더 배웠을까
- 요청: "더 후킹되고 재밌는 주제로 기획"

## 원안 진단 (채널설정 「성과 관찰」 4조건 + 수정·선택 사례)
| 조건 | 원안 | 판단 |
|---|---|---|
| 신체 감각·공포 | 없음 — 「무엇을 더 배웠나」는 교육 제도 설명 | ✗ 짚신·장영실처럼 '정보'로 읽힘 |
| 현대 대응물 | 숨어 있음 | △ **「독해는 되는데 말은 못 하는 영어」**와 똑같은 구조인데 원안 문구에 안 드러남 |
| 노년층 기억 | 문법·독해 위주로 영어를 배운 세대 | ○ 가장 강한 자기 대입 재료 |
| 권력자도 | 없음 | △ 한문 최고 엘리트(사신·선비)도 중국에서 붓으로 대화 — 「엘리트도 막혔다」 평등감 |
- 반려 패턴 대조: 철종 어진 「너무 세부적」 → 제도(사역원)·책 이름(노걸대)을 입구에 두면 같은 꼴. **입구는 누구나 겪은 '영어 울렁증', 제도·교과서는 본문 장면으로.**
- 선택 패턴(T0): 「없던 조선」·현대어 대입(네비·매뉴얼·퇴직), 아는 연결어 + 궁금증 2줄, 상식을 묻는 질문형(낙폭지 「그냥 버렸을까?」).

## 디벨롭 3방향

### ① 조선판 영어 울렁증 — 한문 박사도 중국에선 붓을 들었다 (추천)
- 핵심 질문: 한문을 평생 읽은 선비가 중국 사람 앞에 서면 왜 입을 못 뗐나, 말이 통하려면 무엇이 더 필요했나.
- 상식 뒤집기: 「한자 = 중국 글이니 한문 잘하면 중국어도 되겠지」 → 같은 글자, 다른 소리, 다른 말투(글말 vs 입말).
- 4조건: 공포 ○(외국에서 말 안 통하는 막막함), 현대 ○(시험 영어 vs 회화), 노년층 ○, 권력자 ○(사신단 엘리트도 필담).
- 제목 1 ★: 한문은 술술 읽던 조선 선비, 중국 사람 앞에서는 왜 말 대신 붓을 들었을까
- 제목 2: 한문 잘하던 조선 선비도 중국 가면 말이 안 통했다, 중국어로 말하려면 무엇을 더 배워야 했을까 (원안 질문 보존형)
- 제목 3: 영어 학원 없던 조선, 한문 읽던 선비들은 중국어 회화를 어떻게 배웠을까 (「없던 조선」 꼴)
- 썸네일 A ★: 글은 읽는데 말은 못 해 / 조선 선비의 중국어 울렁증
- 썸네일 B: 한문 박사도 중국 가면 / 붓으로 대화했다?
- 썸네일 C: 한자는 같은데 / 왜 말이 안 통했을까?

### ② 600년 전 중국어 회화책 — 첫 장에 뭐가 나왔나
- 핵심 질문: 조선 통역관 교과서(노걸대)는 무엇부터 가르쳤나 — 여관 흥정, 말 값 깎기, 고기 볶는 법, 길에서 도둑 이야기.
- 강점: 「여행 회화책」 현대 대응물, 장면이 생활사라 3D 연출 쉬움.
- 약점: 「노걸대」는 시청자가 모르는 이름(다물사리 반려 「모르는 이름은 제목·썸네일에 쓰지 않음」). 책 하나는 세부적.
- 제목: 조선판 여행 중국어 책, 중국 가는 상인에게 맨 처음 가르친 말은 무엇이었을까
- 썸네일: 조선판 여행 중국어 책 / 첫 장에 적힌 말은?
→ ①의 본문 중심 장면으로 흡수 권장.

### ③ 외워야 살아남는 통역관 학교
- 핵심 질문: 통역관 지망생은 어떤 훈련을 받았나 — 통째 외우기, 외우지 못하면 매, 시험(역과).
- 약점: 제도사 쪽으로 기울면 저성과 패턴(정치·제도). 「우리말 쓰면 벌」 같은 강한 문구는 원문 확인 전엔 못 씀.
- 제목: 우리말 쓰면 벌을 받았다? 조선 통역관들은 중국어를 어떻게 외웠을까 ← [확인 필요]
- 썸네일: 외우지 못하면 매? / 조선의 중국어 학교 ← [확인 필요]
→ ①의 후반부 한 장으로 흡수.

## 추천 조합
- **제목: 한문은 술술 읽던 조선 선비, 중국 사람 앞에서는 왜 말 대신 붓을 들었을까**
- **썸네일: 글은 읽는데 말은 못 해 / 조선 선비의 중국어 울렁증**
- 맞물림: 썸네일이 「영어 울렁증」으로 자기 대입을 걸고, 제목이 「붓으로 대화했다」는 의외의 장면을 약속한다. 「그래서 말하려면 무엇을 더 배웠나」(원안 질문)는 본문 후반의 답으로 회수 — 제목에서 답(소리·입말·외우기)을 공개하지 않는다(한양_물장수 반려).

## 본문 흐름 가안 (15분 / 약 7,500자)
1. 콜드오픈: 북경 숙소, 조선 선비와 중국 선비가 마주 앉아 말없이 종이에 글을 써서 주고받는 밤(필담).
2. 다리: 한문 최고 엘리트가 왜? — 같은 글자, 다른 소리(조선 한자음 vs 중국 발음) + 글말과 입말의 차이. 「교과서 영어로 원어민 앞에 선 느낌」.
3. 더 배워야 했던 것 ① 소리 — 한글로 중국 소리를 적어 익힌 회화책, 세종 때 음을 물으러 요동까지 오간 학자들.
4. 더 배워야 했던 것 ② 입말 — 회화책 속 장면: 여관 잡기, 밥값·말 값 흥정, 가짜 돈, 아플 때 의원 부르기.
5. 더 배워야 했던 것 ③ 통째 외우기 — 통역관 학교의 훈련과 시험.
6. 반전: 교과서가 낡는다 — 나라가 바뀌면(원 → 명 → 청) 말투가 바뀌어 책을 고쳐야 했다.
7. 결국 말은 누가 했나: 선비는 붓, 입은 통역관(중인). 통역 실수 하나가 외교 사고가 되던 무게.
8. 엔딩: 지금 우리의 영어 공부와 겹치는 장면, 시청자 질문 1회(엔딩에만).
