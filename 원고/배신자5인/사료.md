# 배신자5인(을사오적) — 사료·확인 목록

클라우드 세션 웹 검색으로 확인. 원문 대조(관보·신문 원문·판결문)는 PC에서 보완 필요. ⚠ = 자료마다 다르거나 1곳만 확인.

- S1 을사조약(1905.11.17~18, 경운궁 중명전): 찬성 5대신 — 학부 이완용, 내부 이지용, 외부 박제순, 군부 이근택, 농상공부 권중현. 참정대신 한규설 반대. (한국민족문화대백과 「을사조약」)
- S2 장지연 「시일야방성대곡」 황성신문 1905.11.20 / 민영환 자결 1905.11.30. (한국민족문화대백과)
- S3 이근택 피습 1906.2.16 밤 기산도 등, 침실 잠입, 10여 곳 자상, 한 달여 치료 뒤 생존. 침실 주위 군인·순검 배치. 참여자 명단은 자료마다 다름 ⚠. (독립기념관 theme.archives.go.kr, 순천시 자료 https://new.suncheon.go.kr/file/pdf/kid_politics_6_1_5.PDF)
- S4 자신회(나철·오기호) 1907.3.25 거사, 권중현 저격 — 가벼운 부상. 다른 대신은 일본군 호위로 실패. 나철 등 유배형. (한국민족문화대백과 E0076099 등)
- S5 이완용 집 방화 1907.7(고종 양위 직후) ⚠ 검색으로 직접 확인 못 함 — 원문 확인 전까지 대본에서는 「집이 불탔다」 한 줄, 확인 안 되면 삭제.
- S6 이재명 의거 1909.12.22 명동성당 앞, 이완용 중상·생존, 후유증. 이재명 1910 사형. (서울신문 1999.8.13, Wikipedia Yi Wanyong)
- S7 1910 병합 뒤 조선귀족 작위: 이완용·이지용 백작, 박제순·이근택·권중현 자작. 이완용 1920 후작. (한국민족문화대백과 각 인물)
- S8 이지용 1912 정초 도박 적발, 태형 판결 보도(매일신보 1912.2.1), 백작 예우 1912.4 정지 → 1915 복작 ⚠ 1곳 확인. (https://cpmadang.org/collection/145951)
- S9 사망: 박제순 1916, 이근택 1919.12, 이완용 1926.2.11~12(⚠ 날짜 이설), 이지용 1928, 권중현 1934. (한국민족문화대백과)
- S10 이완용 1919 3·1운동 때 매일신보에 만세 중단 경고문 게재. (한국민족문화대백과 「이완용」)
- S11 이완용 장례 성대, 일제 기록영화. 동아일보 1926.2.13 사설 삭제·호외. 묘는 익산 낭산면. (jjan.kr 2017.8.17, Wikipedia)
- S12 이완용 묘 1979 후손(증손 측) 파묘, 화장해 장암천에 뿌림. 묘 훼손(칼 꽂힘·봉분 파헤침)이 이유. (jjan.kr 2011.9.18, 2017.8.17, 중앙일보 칼럼)
- S13 반민법 1948, 반민특위 1949 활동 후 해체 — 오적 5명 모두 이미 사망. (한국민족문화대백과)
- S14 이완용 증손 국가 상대 토지 소송 승소, 1997.11 북아현동 땅 매도 후 캐나다 이주 ⚠ 판결 연도 미확인. 2005 친일재산귀속법, 이완용 부동산 중 환수는 약 0.5%. (https://v.daum.net/v/bLE5MnqFHN, https://ilyosisa.co.kr/news/article.html?no=257491)
- S15 이완용 독립협회 초대 위원장(1896). 이지용 왕실 친척(흥인군 이최응 손자, 고종 조카뻘) ⚠ 웹 재확인 못 함. 이근택 무관 출신·고종 측근. (한국민족문화대백과 각 인물 — PC 대조 필요)
- S6 보강: 이재명 법정 “공범? 2000만 동포가 도왔다” 취지 답변, 1910.9.30 사형. (서울신문 2019.8.6 https://www.seoul.co.kr/news/2019/08/06/20190806023003)
- S1 보강: 고종은 끝내 재가하지 않음, 11.17 밤 박제순·하야시 곤스케 조인. (서울신문 1995.10.14 등)
- S16 최익현 「청토오적소」(1905, 오적 처단·조약 파기 상소). 상인 철시. (한국민족문화대백과 「최익현」 — PC 대조)
- S17 권중현 조선사편수회 고문 ⚠ (한국민족문화대백과·친일인명사전 — PC 대조, 미확인 시 문장 삭제)
- S18 2009 친일반민족행위진상규명위원회 명단, 2009 민족문제연구소 친일인명사전 — 5명 수록.
