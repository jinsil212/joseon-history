# 숙의 문씨 · 정조 — 사료 (사실 / 출처 / 원문 핵심 / 대본 사용 위치)

확인일 2026-10-12~13. 조선왕조실록 사이트(sillok.history.go.kr)는 이날 접속 거부가 이어져, **한국고전종합DB(db.itkc.or.kr)의 조선왕조실록·신역 실록·일성록 검색 결과(기사 제목·번역 요지·각주)**로 대조했다. 기사 원문 전문을 한 줄씩 대조한 것은 아니며, 아래 인용은 고전종합DB가 보여 준 번역 구절 범위다. 유튜브 견본(한밤 zeo3UNWzR_4, 조선기록관 rPGT_cvTegg)은 미확보.
