# 경신대기근(1670~1671) 한양행 — 사료조사

- 조사일: 2026-11-02 (클라우드 세션)
- **조사 환경의 제약 (반드시 먼저 읽을 것)**: 이 세션의 네트워크 허용 목록에 `sillok.history.go.kr`, `db.itkc.or.kr`, `ko.wikipedia.org`, `ko.wikisource.org`가 없어 **원문 페이지를 직접 열지 못했다**(curl은 프록시 403, WebFetch는 DNS 실패). 따라서 아래 모든 항목은 **웹검색 결과 요약(검색엔진이 보여준 실록 페이지 제목·발췌, 2차 글의 인용)**을 거친 것이다.
  - 그래서 이 문서에는 **「확인(원문 봄)」 항목이 하나도 없다.** 원고에 쓰기 전에 PC에서 실록 URL을 직접 열어 문장을 대조해야 한다.
  - 표시 규칙
    - **실록ID 확인·문장 미대조**: 검색 결과에 실록 사이트의 기사 URL·제목이 나왔고 번역문 일부가 발췌됐지만, 기사 전문을 내가 직접 읽지는 못함. 사용자 분류로는 「2차자료만」에 들어가지만, PC에서 확인하기 가장 쉽다.
    - **2차자료만**: 블로그·신문·나무위키·칼럼에만 나옴.
    - **미확인**: 찾지 못했거나 출처끼리 어긋남.
- 실록 ID 읽는 법: `kra`=현종실록, `krb`=현종개수실록. 예) `krb_11204005_004` = 현종개수실록 12년 4월 5일 4번째 기사. 주소는 `https://sillok.history.go.kr/id/{ID}`.
- 날짜는 모두 음력.

## 원고에 쓸 수 없는 것 / 불확실한 것

1. **이 문서의 어떤 문장도 아직 「원문을 직접 본 것」이 아니다.** 실록 사이트에 접속하지 못해 검색 요약만 거쳤다. 대본에 따옴표로 실록을 인용하려면, PC에서 아래 ID를 먼저 열어 문장을 대조해야 한다.
   - 우선 대조: `krb_11204005_004`(금산 죽소), `krb_11204017_001`(5월 15일 진소 폐쇄), `kra_11203021_002`(순례), `kra_11212005_002`(윤경교), 현종 11년 5월 2일(현종 자책), 현종 12년 1월(서울 세 곳 설죽소), 2월 29일(팔도 여역), 4월 12일(남용익 시체 수레), 4월 29일(진소 한 곳 1만여 명).
2. **용산·홍제원 진휼소 추가 설치**: 신문 칼럼에만 나옴. 실록 문장 미확인.
3. **서울 설죽소 설치 날짜**: 1월 1일인지 16일인지 엇갈림.
4. **88,150명 / 8만 5천 명**: 출처가 서로 다르고 실록 문장 미확인. 숫자를 쓰지 않는 편이 안전함.
5. **'100만 명 사망'**: 당시 상소의 표현(윤경교·장선징)으로만 쓰고, 확정된 통계처럼 쓰지 않는다.
6. **"죽을 먹다가 죽었다 = 갑자기 먹어서 죽었다(재급식)"로 잇는 서술**: 경신대기근 실록에서 그런 인과를 쓴 문장은 찾지 못했다. 구황서의 경고(B1~B4)와 금산 사례(B5)를 **나란히 놓을 수는 있어도, 실록이 '많이 먹어 죽었다'고 했다고 쓰면 안 된다.**
7. **도성 유입 차단·환송 조치, 한양까지의 거리, 길에서 죽은 수**: 찾지 못했다. 지어내지 말 것.
8. **죽은 어미 젖 빠는 아이**: 날짜 표기가 앞뒤가 안 맞고 한양 장면인지도 불명. 사용 보류.
9. **'숨이 붙은 사람이 시신과 함께 수레에 실려 나갔다'**: 칼럼이 '현종실록'이라고만 함. 날짜 미확인, 사용 보류.
10. **순례·금산 부부 일화는 한양 일화가 아니다.** 한양행 주제에 넣으려면 "지방에서는" 맥락으로만 쓴다.
11. **동·서활인서 수천 명 입원, 쌀 3만 6,760석, 현종 금주**: 칼럼 단독 출처. 확인 전에는 쓰지 않거나 "전해진다"로 낮춘다.
12. **우역 소 마릿수, 우박 날짜**: 블로그 정리. 확인 전에는 숫자 없이 "우박·서리·가뭄·홍수·메뚜기·소 돌림병이 겹쳤다" 정도로만 쓴다.
13. **『신간구황촬요』 한문 구절**: 검색 발췌라 글자가 정확한지 위키문헌·영인본으로 재확인 필요. 우리말 풀이(B2)는 언해 원문이 아니라 현대 풀이일 수 있다.
