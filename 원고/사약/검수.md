## 2. G5-2 증거표

| 검사 | 실제 근거 |
|---|---|
| 핵심 집중 | 질문: 조선은 왜 죽음을 ‘내렸고’, 그 죽음은 어떻게 은혜라 불렸나. 답: “사사가 무엇을 내린 것이었는지 … 죽음 그 자체가 아니라, 죽는 방식” + “임금은 … 신하를 죽이면서도, 법보다 너그러운 임금으로 남을 수 있었던 겁니다.” 뺀 곁가지: 주초위왕 야사, 현량과, 다른 사사 사례(송시열·장희빈·경빈 박씨·강빈), 능지처사, 사약 의식 통설. 가장 삭제를 검토한 설명: 1장 위훈 삭제 문단(“공신 일흔여 명의 공을 지우자고”) — 유지 이유: 한 달 사이 처분이 바뀐 배경(누가 조광조를 미워했나)이 없으면 ‘사람들이 놀랄 것 같다’ → 사사로 바뀐 계산을 이해할 근거가 없음. 2차 출처(교차 일치)라 수치는 ‘일흔여 명’으로 둥글게 |
| 초보자 이해·등장 시점 | ‘사사’는 2장에서 “그것이 사사, 임금이 죽음을 내리는 처분입니다”로 기능 뒤 이름. 도입·1장은 ‘죽음을 내린다’로만 씀. ‘의금부 도사’는 “왕명으로 죄인을 다스리는 관청에서 보낸 관리”, ‘대부의 줄’은 “나라의 높은 벼슬아치 자리”, ‘왕망’은 “옛 중국에서 임금 자리를 빼앗은 신하”, ‘붉은 마음’은 “변하지 않는 충성”으로 바로 풀이. 효경 인용은 “조선의 선비들이 어려서부터 외던 효경이라는 책”으로 정체 먼저 |
| 중복·전환 | 1장 끝 “죽음이 어떻게 가벼운 벌이 될 수 있었을까요?” → 2장 첫 “법이 정한 사형은 크게 두 가지” (H9 ‘그래서’ 성립). 2장 끝 “조광조의 마지막 하루가 그것을 보여 줍니다” → 3장 “다시 능성의 그날로”. 도입의 질문 “글은 없소?”는 3장에서 쪽지·대부의 줄로 이어 받고, 마무리에서 “임금이 내린 죽음이어야 … 신하로서”로 새 의미를 얹어 회수(B13) |
| 제목·썸네일 약속 회수 | 썸네일 “‘사’는 죽을 사가 아니다” ↔ 도입 “사약의 사는 내릴 사입니다” + 4장 사전 풀이. 제목 “죽음이 은혜라고 불린 이유?” ↔ 2장 “법이 정한 가장 무거운 사형과 비교하면 … 두 칸이나 낮춘 처분”, 3장 “죽는 방식”, 5장 “명령의 말은 은혜였습니다” |
| 유튜브 정책·표현 순화 | 형벌은 “목을 베는 형벌 / 목을 매는 형벌”, “몸이 둘로 나뉘는” 한 번만. 집행 장면·고통·시신 묘사 없음. 조광조의 죽음은 “내려온 것을 마셨습니다”, “많이 마시고 죽었다”(실록 인용)까지. 화면·음향 제작물 미검토 |
| 사실·분량 | 주장 출처: 중종실록 1519.11.16(사사 → 감사 유배, 기사관 붓, 영의정 반대), 12.14(유생 상소: 은혜·참형), 12.16(전교 ‘말감’·조광조 사사, 비현합 ‘뿌리’ 발언·삼공 교체, 사관의 마지막 하루 기록), 한국민족문화대백과 「교형」(교형을 낮추어 사사), 표준국어대사전 ‘사약(賜藥)’. 2차: 위훈 삭제 76명·선조 때 영의정 추증. 한계: 사약 재료 원전 없음(대본에서 ‘알 수 없다’로 처리), 사망 날짜 미기재, ‘사극 장면이 대개 집 마당’은 작업자 관찰 |

## 3. G5 정합

- P16: 클릭 이유(사약이 왜 ‘내리는’ 것·은혜였나) = 제목(죽음이 은혜라고 불린 이유?) = 썸네일(‘사’는 죽을 사가 아니다 / 왜 죽음을 ‘내렸을까’?) = 첫 문장(“죽음을 내린다는 명만 있고, 그것을 적은 글은 없소?”).
- T11: 제목 명사 ‘이유’ → 원인 설명이 본체(2장 형벌 비교·3장 받은 것·5장 계산).
- B24: 마무리 명사 — 능성·방·시(3장 “마지막 시를 적었습니다”), 쪽지(3장), 임금·신하(1·3장). 시의 본문은 마무리에서 처음 공개(3장에서 심고 회수).
- G5-1 역검토: 3장이 가장 길어 ‘조광조 최후’ 인물 이야기로 흐를 위험 → 3장 끝 “사사가 무엇을 내린 것이었는지 … 죽는 방식”으로 질문 축에 묶음. 4장(재료)은 질문과 다른 호기심이지만 “이름은 누가 내렸느냐에서 온 것”으로 핵심 답에 연결되어 유지.

## 4. 겹침 대조

- 같은 묶음 19 임꺽정: 임꺽정 편 마무리 “3년 뒤 정월, 그는 붙잡혀 처형됐습니다” 외에 사형 설명 없음. 이 편의 형벌 설명과 겹치지 않음. 두 편 모두 ‘실록을 쓰던 관리’ 표현을 쓰지만 채널 공통 풀이어이며, 도입(장면형 ↔ 대사형)·착지(사료 문장 ↔ 인물의 시)·진입 문형(“그해 봄으로 가 보겠습니다” ↔ “말 속에서 먼저 시작됩니다”)이 다름.
