## 2. 나이 표기

- 백과사전 생몰년 1536~1623 → 세는 나이로 1623년 88세. 우리역사넷도 “88세가 되던 1623년”이라고 적음(출생은 1535년으로 적어 1년 차이). 대본은 “여든여덟”만 쓰고 출생 연도는 쓰지 않는다.
- 임진왜란 의병 때 나이: 우리역사넷 “57세”. 대본은 “쉰일곱”.

## 3. 쓰지 않은 것(확인 못 함·야사·견본 주장)

- “조선 최고령 사형수/최고령으로 처형된 영의정”: 전체 사형 기록을 대조할 수 없어 확인 불가 → 제목·본문에서 ‘최고령’을 쓰지 않고 ‘여든여덟에 처형된 영의정’으로 바꿈(P11, 같은 강도의 대안: 실록의 ‘늙어 죽기 전에 죽이자’).
- “정승을 지낸 사람·80세 이상은 목을 베지 않는다는 관례”: 견본(ref 007)과 위키백과에만 있고 법 조문·실록으로 확인하지 못함 → 사용 안 함.
- 처형 장소(군기시 앞), 압송 거리(천 리), 압송 중 태도(허리는 무너졌는데 목은 꼿꼿): 견본의 장면·전언 → 사용 안 함.
- 국문 때 다섯 가지 죄목, “90세 모진 목숨…” 진술: 위키백과에만 있고 원전 미확인 → 사용 안 함.
- 조식이 칼을 물려주었다는 이야기: 원전 미확인 → 사용 안 함.
- 합천에서 체포했다는 사실은 실록에 장소가 명시되지 않음. 백과사전의 ‘합천에 머물렀다’와 실록의 ‘잡아 왔다(拿來)’를 합친 서술이므로 대본에는 “합천에 머물던 그를 잡아 올렸다”로만 쓰고 체포 장면은 그리지 않음.
- 압송 날짜(3월 28일): 위키백과만 근거 → 쓰지 않고 실록의 “잡아 온 지 사흘”만 사용.
