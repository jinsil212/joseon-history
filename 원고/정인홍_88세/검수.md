## 3. G5 정합

- **P16 네 줄:** 클릭 이유 = 곧 죽을 88세 노인을 왜 서둘러 죽였나 / 제목 = “여든여덟 노인을 기다리지 않고 처형한 이유?” / 썸네일 = “늙어 죽을까 봐 서두른 처형 / 여든여덟 영의정 정인홍”(같은 상황을 ‘늙어 죽을까 봐’로 확장) / 첫 문장 = “1623년 봄, 조선 조정은 여든여덟 살 노인이 저절로 죽을까 봐, 서둘러 처형해 달라고 왕에게 청했습니다.” — 같은 질문.
- **T11:** 제목 명사 ‘이유’ → 원인 설명 본체는 5장 “여기서 처음의 질문에 답할 수 있습니다.” 이하. 도입 마지막 문장 “그 답은 … 바로 그의 이름에 있었습니다.”가 ‘이유’를 받음.
- **H9:** 도입 끝 “그의 이름에 있었습니다.” + 1장 첫 “정인홍은 경상도 합천 사람입니다 … 수제자로 꼽혔습니다.” → ‘그래서(그 이름이 어떻게 생겼나)’ 성립.
- **B24 클로징 명사:** 제자들·합천(1장·2장), 역적(5장 죄목), 1908·대한제국(새 정보), 의자와 지팡이(도입·2장), 사흘(도입·5장). 285년은 마무리에서 처음 나오는 계산값(1623→1908)으로 새 정보.
- **H2·H18:** 시청자 위치는 처음부터 끝까지 ‘조선 조정의 문서를 따라가는 현재의 청취자’. 시점 이동 없음.

## 6. 반복 감시어 (S3-2)

감시어 ‘이름’(본문 약 20회). 각 등장 자리의 새 정보 확인: 1장 “자리보다 이름에서 나왔습니다”(의병을 모은 힘) / 2장 “그 이름은 조정 한가운데”(원격 정치) / 2장 “정권을 받치는 든든한 이름”(지지 세력) / 3장 명부에서 ‘이름’ 삭제(실제 명부) / 5장 “헛된 이름”(사관 평) / 5장 “평생 쌓아 온 이름”(반정의 표적) / 마무리 “역적의 이름”(사후). 같은 메시지 재진술은 5장 끝 문장 하나 → 삭제(2절 ①).

## 8. 같은 묶음 3편 문장 겹침 자동 대조 (2026-10-13, 최종본 기준)

세 편 낭독문을 8글자 조각으로 대조해 겹치는 문장을 찾았다(자동 검색은 누락 확인용이며 이해·재미 판단 근거가 아님). 걸린 문장과 조치:
- 김자점 1장 “조선의 신하가 오를 수 있는 가장 높은 자리, 영의정까지” ↔ 정인홍 2장 “신하로서 오를 수 있는 가장 높은 자리, 영의정” → 김자점 쪽을 “신하 가운데 으뜸인 영의정까지 지낸 사람입니다”로.
- 김자점 1장 “인목대비를 대비 자리에서 끌어내리자는 논의가 벌어졌을 때” ↔ 정인홍 4장 “인목대비를 대비 자리에서 끌어내리자는 주장” → 김자점 쪽을 “인목대비를 내치자는 논의에 반대했다가, 대북 쪽에 밀려 쫓겨난 겁니다”로.
- 광해군 편과의 겹침(군 강등, 청군 침입, 진도 자결 문장)은 광해군 편 쪽을 고침(광해군 검수.md 참조). 정인홍 편 본문은 수정 없음.
