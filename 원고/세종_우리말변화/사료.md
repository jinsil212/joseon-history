# 세종_우리말변화 — 사료

- 2026-11-02 정리. 이번 세션은 실록(sillok.history.go.kr)·위키문헌·한국민족문화대백과 접속이 네트워크 정책으로 막혀(접속 거부·DNS 실패) **1차 원문을 직접 열지 못했다.** 웹 검색 결과에 실린 기관·언론·연구 요약으로만 확인했다.
- 상태: ● = 서로 다른 출처 둘 이상이 같은 내용을 전함(원문 직접 대조는 아님) / ○ = 출처 하나 또는 일반 국어사 지식, 대본에서는 「~로 봅니다」「~다고 합니다」로만 씀 / ✕ = 확인 못 해 대본에 쓰지 않음
- **녹음 전 필수**: 아래 ● 항목도 실록 국역·해례본 영인본 원문 화면에서 한 번 더 대조.
