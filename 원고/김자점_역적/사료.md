## 쓰지 않은 것

- 능지처참의 신체 묘사, 형장 장면(S14). 실록은 ‘정형’으로만 적음 → 대본은 “법이 정한 가장 무거운 형벌”.
- 소현세자 독살 가담: 백과도 “가담한 듯하다”는 추정 → 사용 안 함.
- 견본의 ‘정방산성에서 꼼짝도 안 했다’, ‘부하 장수의 출격 요청 거부’, ‘손녀가 인조 후궁’, ‘청에 여러 차례 첩서’: 확인 못 함 또는 오류 → 사용 안 함.
- 김구가 김자점의 몇 대 방계인지, 11대조의 이름: 백범일지 외 확인 자료 없음 → ‘11대 조상’만.
- ‘300년’: 1651년 처형~1876년 김구 출생은 225년 → 대본은 “2백 년 넘게”.
