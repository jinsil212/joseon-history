## 견본(한밤 012)에서 확인되지 않아 쓰지 않은 것

| 견본 주장 | 판정 |
|---|---|
| 황보인이 사위 삼으려 했고 한명회가 거절, 살생부 맨 위에 황보인 | 이번 확인 범위에서 근거 없음. 사용 안 함 |
| '다섯 핏줄이 모두 짧은 생' — 예종·손자 한경침(1504년 22세) 포함 | 예종은 사위이지 핏줄이 아님. 한경침의 생몰은 이번에 독립 출처로 확인 못 함 → 사용 안 함 |
| 한명회가 대비 앞에서 자을산군을 밀었다는 대사 | 실록 즉위 기사에 한명회 발언 없음(#7) → 사용 안 함 |
| 장순왕후가 '다섯 살배기'를 안고 쓰러짐, 세조가 손자에게 직접 약을 떠먹임 | 근거 미확인·자막 오류 의심 → 사용 안 함 |
| 한명회 목을 한양 거리에 매달았다 | 부관참시 결정·시행(#10·#11)만 확인. 효수 세부는 미확인 → 사용 안 함 |
| 단종의 저주 | 당시 수근거림이라는 기록 미확인 → 대본에서 '저주' 틀을 쓰지 않음 |
| 한보가 '무식·광망·행패'로 실록에 적혔다 | 미확인 → 사용 안 함. 졸기의 '아들 한보' 존재만 사용 |

## 확인 못 한 것(남은 한계)

- 장순왕후 졸기 본문(세조실록 7년 12월 5일) 국역 전문은 화면에 나오지 않아 날짜·표제만 확인. 출산·사망 세부는 한국민족문화대백과 '공릉'에 의존.
- 한보의 이후 행적, 갑자사화 때 한명회 가족의 처벌 범위는 미확인 — 대본에서 다루지 않음.
- 1482년 사약 결정 자리에서 한명회의 개별 발언은 확인하지 않음(같은 달 11일 '한명회가 윤씨의 일로 대죄를 청하다' 기사는 내용이 모호해 사용 안 함). 대본은 1479년 폐위 자리의 발언과 1504년 기사의 '처음엔 간하다 따랐다'만 씀.
- 공혜왕후의 '병치레가 잦았다'는 2차 자료(경기일보 2020-08-03, 파주 삼릉 안내) 표현 → 대본은 지문의 병 경과(1473 여름 발병·겨울 재발·1474 봄)만 씀.
- 연산군의 세자 책봉 연도(1483)는 이번에 독립 출처로 확인하지 않음 → 대본은 연도 없이 "그 무렵 세자가 되어 있었습니다".
- 한명회가 종묘(성종 또는 세조 묘정)에 실제 배향됐는지 미확인 → 4월 18일 명령을 조건문 그대로 씀.
