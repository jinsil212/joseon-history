## 2. 정합 (G5)

- 네 줄: 클릭 이유(왕위를 놓친 세종의 형이 어떻게 아홉 왕을 무사히 지나 91세까지) ↔ 제목 “세종보다 36년을 더 산 형 효령대군, 왕위를 놓치고도 아홉 명의 왕을 무사히 지나간 이유?” ↔ 썸네일 “왕위를 놓친 세종의 형 / 아흔한 살까지 어떻게 살아남았나?” ↔ 첫 문장 “아흔한 살까지 산 왕자가 있습니다. 그가 사는 동안 조선의 왕은 아홉 명이었습니다.” → 넷째 문단 “그런 사람이 어떻게 아홉 왕의 시대를 무사히 지나갔을까요?” 같은 질문.
- T11 ‘이유’ 지급: 4장 끝 “이 집안에서 칼은 늘 왕의 자리를 흔들 수 있는 사람을 겨눴습니다 … 왕들에게 효령은 겨눠야 할 사람이 아니라, 불러서 일을 맡길 사람이었던 겁니다.” 마무리 “끝까지 쥐지 않은 것이 하나 있었습니다. 왕의 자리입니다.”(B21).
- 제목 수치 지급: ‘36년’ 도입·마무리, ‘아홉 명의 왕’ 도입·5장(“그 사이 조선의 왕은 아홉 명이었습니다”).
- H9: 도입 끝 “태종이 … 남긴 말부터 들어 보겠습니다.” → 1장 “1418년 6월, 태종은 맏아들 양녕을 세자 자리에서 내립니다.” → 셋째 문단에서 그 말. 이어짐.
- H28 도입 재검: 도입의 죽음 나열(외삼촌·맏형·조카·조카손자)은 2장(외삼촌), 1장(맏형), 4장(안평·금성·단종·화의군)에서 이름과 경위로 회수 — 4장에 “도입에서 말씀드린 … 바로 이들입니다.”로 명시.

## 3. 역검토 (G5-1)

- 도입 → 궁금: 왜 가장 가까웠던 사람이 무사했나.
- 1장 → 해결: 왜 건너뛰어졌나(태종의 말). 야사로 절과의 연결. 남음: 다음 차례였던 사람은 위험하지 않았나?
- 2장 → 해결: 칼은 왕 자리 흔드는 사람을 겨눈다(외삼촌), 효령은 아버지가 부리는 아들. 남음: 동생 왕 아래서는?
- 3장 → 해결: 세종이 찾아감, 효령은 신하들이 싫어하는 불교 일 → 신하를 모을 수 없는 자리. 남음: 세조의 피바람은?
- 4장 → 해결: 처벌 요청(현재 왕 편), 원각사, 사관의 ‘세조 불교’ 평 → 답.
- 5장 → 결과(잔치·춤) + 반전(재물 비판).
- 마무리 → 쥔 것과 쥐지 않은 것으로 답 확정.
- 가장 삭제를 검토한 설명: 2장 “활을 쏘면 다섯 발을 모두 맞혀 …” — 빼도 흐름은 이어지나, ‘자질이 약하다’던 아들이 경쟁자가 될 수 없는 사람이 아니었다는 점(질문의 긴장)을 받쳐 유지. 3장 내불당 문장 — ‘왕에게도 쓸모 있는 일’의 근거라 유지.
- 기존 실패 대조(정명공주 도입 세부 과다): 도입에 이름은 효령·세종·태종만, 연도·사건 세부 없음.

## 5. 중복·전환

- 감시어 ‘칼’(6회): 2장 기준 세움 → 3장 끝 없음 → 4장 제목·답 → 마무리 재물/왕위 대비. 매번 같은 주장을 반복하는지 대조: 2장(기준), 4장(효령에 적용), 마무리(재물과 구별) — 각각 새 관계를 더함.
- 경계: 2→3 “이제 효령 위에는 동생인 왕이 있었습니다.” → “형이 동생을 왕으로 모시는 자리.” / 3→4 “효령의 조카 하나가 왕의 자리를 차지합니다.” → “세종의 둘째 아들 수양대군. 효령에게는 조카입니다.” / 4→5 답 → “세조가 세상을 떠나고 …”(시간 이동, 결과 확인 목적) / 5→마무리 “왕들은 끝까지 그를 곁에 두고 찾아갔습니다.” → 질문 회수.

## 6. 기존 원고·이웃 편 겹침

- `양녕_어리`: 어리 사건·양녕의 글 장면 없음. 양녕 폐위는 1장 첫 두 문장으로만. 양녕 이름은 1·3·4장에 짧게.
- `원경왕후`: 민씨 형제 대목을 2장 한 문장(“외삼촌 넷을 차례로 귀양 보내고 끝내 모두 목숨을 끊게 했습니다”)으로만.
- 신빈김씨(같은 묶음): 계유정난 문장 겹침을 고침(1절). 신빈·혜빈 등장 없음. 답 원리도 다름(신빈: 아들들이 정난 때 선 자리 / 효령: 왕과 겨룰 사람이 아니라 불러 쓰는 어른).
- 14 단종편_세조편: 단종 죽음은 한 구절, 사육신 없음.
- 견본 002·이원익과 문장 대조: 002의 왕별 서술 문장, 이원익의 ‘빈손’ 결론을 가져오지 않음(오히려 “빈손은 아니었다”로 다름을 밝힘).
