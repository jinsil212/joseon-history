## 쓰지 않은 것

- 1418년 출가·1422년 환속설(실록위키 “~한 것 같다” 추정, 당대 실록 기사 미확인) — 사용 안 함.
- 선조실록 1603년 ‘양녕이 밤에 효령에게 귓속말’ 이야기 — 185년 뒤 기록, 북 야사와 중복 → 사용 안 함.
- “계유정난에 가담하지 않았다”(나무위키) — 독립 출처 없음 → 사용 안 함.
- 1434년 계달 문서 서명 사양 — 의미 해석이 출처마다 달라 사용 안 함.
- 세종이 효령을 ‘청권’에 빗댔다는 일화 — 전해지는 이야기, 출처 약함 → 사용 안 함.
- 효령의 북 ‘터졌다’ — 자료는 ‘늘어졌다’ → ‘늘어졌다’로만.
