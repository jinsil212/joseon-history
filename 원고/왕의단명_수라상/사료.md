## 확인했지만 쓰지 않은 것 / 확인 못 한 것

- "주상은 고기가 아니면 수라를 들지 못한다"는 태종 유언: 실록 원문 문구 확인 못 함 → 사용 안 함.
- 세종이 "물을 하루 한 동이" 마셨다는 이야기(한밤 009·2차 칼럼): 실록 원문 미확인 → 사용 안 함. 소갈증 자체(F3)만 씀.
- 한밤 009의 "세종이 임질(성병)을 앓았다": F3의 '임질(淋疾)'은 한의학의 소변 병이다. 성병으로 단정하지 않으며 대본에도 쓰지 않음.
- 백성의 평균 수명과 왕의 수명 비교: 영유아 사망을 포함한 신뢰할 통계가 없어 쓰지 않음. 대기열 hook의 "백성 못지않게 짧았다"는 "왕 스물일곱 명 가운데 열한 명이 마흔을 넘기지 못했다"(F5)로 바꿈(기획 P11 기록).
- 견본 역사MSG·역사 한 소절 영상 자막: 미확보(편 폴더 `원본/` 비어 있음). 제목만 소재추천.md·최근돌파영상.csv에서 확인.
- 정조 종기·피재길·백광현: 기존 `가난한백성_의료`가 대표 장면으로 사용 → 쓰지 않음.
