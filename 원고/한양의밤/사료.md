## 확인 못 한 것 · 쓰지 않은 것

- 정조 20년(1796) 진사 이정용 음주·야금 사건: 검색 요약에만 등장, 원문 확인 실패 → 쓰지 않음.
- 『대명률』 야금 조문(1경 3점 이후 태 30, 2~4경 태 50, 공무·질병·출산·초상 예외): 중국 웹 인용만 → 조선 시행 규정은 N3·N4로만 말함.
- 1895년 폐지: 언론(N14)만 → ‘1895년 무렵 사라졌다고 합니다’로 성격 표시.
- 통금 시각: 백과(밤 10시경)와 신문(평균 8시 30분경)이 다름 → “대략 밤 10시 무렵”(백과)에 “절기·시기마다 달랐다”(우리역사넷·신문)를 붙여 씀.
- 상원·섣달그믐 정기 해제의 1차 근거: 미확보 → 상원은 N11 전언, 초파일은 N9.
- 경수소의 수·위치: 미확인 → 말하지 않음.
- 종루의 원래 자리: 백과(종로·남대문로 네거리)와 신문(탑골공원 옆 인사동 입구)이 엇갈림 → 백과 표현만 쓰고 보신각은 ‘종루를 잇는 건물’로만 표현.
- 제야의 종 33번 타종: 이번에 출처 확인 못 함(웹 검색 한도 소진) → 횟수는 말하지 않음.
- 자격루(물시계)와 종루 시보의 연결: 웹 검색 한도 소진으로 확인 못 함 → 쓰지 않음.
