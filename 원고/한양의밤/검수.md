# 한양의밤 — 검수 (G장)

- 검토 파일: `대본_v1.md`(파트 3개 조립본), `대본_v1_읽기용.txt` — 최종 수정 뒤 재생성·재열람해 전문 통독.
- 분량: 낭독 본문 **공백 제외 3,944자**, 300~315자/분 가정 약 12.5~13.1분(음성 미측정, 추정). 목표 4,500자보다 약 550자 적음. 이 편 작업 중 국사편찬위원회 실록 사이트 접속 거부, 이어 웹 검색 한도(세션 공용 200회) 소진으로 추가 사례(밤길 사건 실록 원문, 자격루와 종루 시보 연결 등)를 확보하지 못함. 확인 안 된 사례로 채우지 않고(P14), 같은 말 반복으로 늘리지 않음(S3-3). 10분 하한 충족.
- 장별: 도입 228 / 1장 약 560 / 2장 398 / 3장 406 / 4장 약 790 / 5장 약 420 / 6장 약 750 / 마무리 약 390. 낭독문 안 가운뎃점 0(머리말 후보 목록에만 있음), 화면 지시 없음.

## 2. G5-2 최종 근거표

| 검사 | 실제 근거 |
|---|---|
| 핵심 집중 | 질문: 종이 울린 뒤 길에 서 있는 것만으로 왜 죄였나, 그 밤은 어떻게 돌아갔나. 답 원리 하나: “한양의 밤이 장소가 아니라 시각으로 다스려졌기 때문입니다”(마무리)를 1장(종)→2장(경·점, 북 295·징 303)→3장(경별 매 10·20·30·20·10)→4장(경·날짜로 나눈 순라)→6장(풀리는 것도 정해진 사정·날짜)이 받침. 뺀 곁가지: 대명률 조문, 평양·경주·개성의 종(다른 도시), 이정용 사건(원문 미확인), 서순라길 현대 지명. 삭제를 가장 검토한 설명: 5장 관리 사건 — ‘시각’ 원리와 직접 관계가 약해 보였으나, 도입의 “그것만으로 붙잡혀”가 신분과 무관했음을 사람으로 증명해 유지 |
| 초보자 이해·등장 시점 | ‘종루’는 첫 문장 “종루의 큰 종”, 1장에서 위치 설명. ‘인정’은 기능(밤을 알리는 종) 뒤 이름. ‘경’은 “밤을 다섯 토막으로 … 한 토막을 경”. ‘경수소’는 이름 직후 풀이. ‘형조 낭관’은 “형벌을 맡은 관청인 형조의 … 실무 관리”. ‘파루’는 33번 종 장면 뒤 이름 |
| 중복·전환 | 1장 끝 “또 다른 소리가 한양에 울리기 시작합니다” → 2장 경·점의 북·징. 2장 끝 “매의 숫자” → 3장. 3장 끝 “누가 맡았을까요?” → 4장. 4장 끝 “높은 벼슬을 가진 사람이” → 5장. 5장 끝 “벼슬도 길을 열어 주지 못했던 겁니다” → 6장 “누구도, 어떤 이유로도 … 없었을까요?” |
| 제목·썸네일 약속 회수 | 제목 “종이 울리면 길에 서 있는 것만으로 죄, 해가 진 뒤 조선 한양은 어떻게 됐을까” → 1~6장 전체가 저녁부터 새벽까지 순서로 지급, 마무리 한 문장 답. 썸네일 “통금 어긴 한양 사람 / 한밤일수록 매가 늘었다” → 3장 “밤의 한가운데로 갈수록 매가 늘었다가, 새벽 쪽으로 가면서 다시 줄어드는 겁니다” |
| 유튜브 정책·표현 순화(S14) | 매질은 횟수만 말하고 장면 묘사 없음. 1637년 사건은 “도적이 사람을 죽이고 집에 불을 지른 일” 한 문장으로 사실만 |
| 사실·분량 | 핵심 근거: 백과 「인정」·「순라군」·「관등놀이」·「다리밟기」, 우리역사넷 「시보, 인정과 파루」, 조선왕조실록사전 「야금」·「순라」(효종·인조 실록 원문 인용). 한계: 실록 사이트 직접 대조 못 함, 대보름 통금 해제·허가서·1895년 소멸은 언론 전언(대본에 ‘~고 합니다/전해집니다’), 통금 시각은 자료마다 다름(‘대략 밤 10시 무렵’ + 절기별 차이). 3,944자, 추정 12.5~13.1분 |

## 4. G5-1 역검토

- 낭독문만 읽은 역요약: “한양의 밤을 종소리가 닫고 북·징이 시각을 세며, 몇 경이냐로 매의 수까지 정했고, 관리도 예외가 없었으며, 급한 사정과 명절에만 밤길이 열렸다가 새벽 종으로 다시 열렸다는 이야기.” → 기획 5절과 일치.
- 새로 배워야 하는 구간이 이어지는 곳: 4장 “조선 초기에는 순청…”부터 “미리 정해 둔 겁니다”까지(순청·표신·포도청·8구역·세 군영·궁궐). 조직 이름이 많아 가장 무거운 구간 → 군영 이름을 빼고(띠 목록 삭제) ‘경과 날짜로 나눴다’는 원리 문장으로 묶음. 남은 이름(순청·포도청)은 4장 1637년·5장 1650년 사건에서 다시 쓰여 유지.

## 5. 중복 대조

- 기존 `백성의하루`: 농촌 여름 저녁(등잔·바느질) — 도시 통금 장면 없음, 겹침 없음.
- 기존 `한양_물장수`: 새벽 물지게 — 이번 편에 새벽 장면은 파루 종소리뿐, 물장수 언급 없음.
- 같은 묶음 02(과거): 성균관·1686년 사고는 이번 편에 없음. 23(유배길): 의금부·형조는 23편에서 ‘호송 담당’, 이번 편에서 ‘형조 낭관 사건’으로 역할이 다름.
- 장 끝 질문으로 다음 장을 여는 꼴이 세 편에 공통으로 많음(B14 참고) — 같은 문장 반복은 없으나 다음 수정 때 일부 장을 서술형 전환으로 바꿀 여지.
