원문:
> 兵曹啓曰, 政院啓辭, 伏見兵曹黃海道價布坡州逢賊事回啓, 則只請價布蕩滌, 而不言明火賊窮尋捕得之事, 疎漏甚矣, 坡州卽距京咫尺之地, 而所謂炭幕, 乃官門之前也, 火賊恣行, 公私齎貨之人, 自前累見殺越, 誠可寒心, 客人被殺, 主人不傷, 亦爲可疑, 嚴設機察, 期於捕得事, 令兵曹移文本道, 各別申飭, 何如事。入啓。傳曰, 允。兵曹謄錄

| 번호 | 내용 (국역 요지) |

| A1 | 황해도의 가포(價布)를 파주에서 도적을 만나 빼앗긴 일로 병조가 회계(回啓)를 올림 |
| A2 | 그 회계는 가포를 **탕척(蕩滌)해 주기만 청하고**, 명화적을 철저히 수색해 체포하는 일은 언급하지 않음 → 승정원(정원): 「매우 엉성하다(疎漏甚矣)」 |
| A3 | 파주는 서울과 **지척**이고, 이른바 **탄막은 관문(官門) 앞**인데도 명화적이 도적질을 자행 |
| A4 | 공물이든 사물이든 재물을 지니고 가는 사람을 **전부터 자주 살해**(累見殺越) — 「참으로 한심스럽다」. **횟수·인원 기록 없음** |
| A5 | **객만 피살되고 주인은 상해를 입지 않은 것도 의심스럽다**(客人被殺, 主人不傷, 亦爲可疑) — 주인 공모 단정 아님 |
| A6 | 엄히 기찰(機察)을 시행해 기필코 체포하도록, 병조가 **본도(本道)에 이문(移文)**해 각별히 신칙하자고 건의 → 입계 → **「윤허한다」** |
| A7 | 《병조등록》에 의거. 번역원 주석: 용례상 「전교하셨습니다」 다음에 병조의 계사가 이어져야 하는데 **이 기사에는 빠져 있다** |
