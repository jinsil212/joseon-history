## 흐름
김홍도 「서당」 속 우는 아이(재현)를 줄기로: ① 우는 아이 → ② 오늘의 길 → ③ 첫날 천자문(텬) → ④ 아침 배강·대통~불통 → ⑤ 새 대목 백 번 읽기 → ⑥ 붓과 놀이(초·중·종 놀이) → ⑦ 명절 방학 → ⑧ 불통과 회초리(부모가 보낸 싸리) → ⑨ 양아록 「종일 마음이 아팠다」 → ⑩ 천 글자를 처음부터 끝까지 → ⑪ 책거리(송편)·다음 날 동몽선습 → ⑫ 지금 남은 것(1930년 서당 수, 교실 책거리)
