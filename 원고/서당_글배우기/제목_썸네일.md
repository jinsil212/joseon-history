# 서당_글배우기 — 제목·썸네일 후보 (2026-11-02)

주제: 조선 아이들은 어떻게 글을 배웠을까 — 서당의 하루

## 형식 근거(T0, 작업자 해석)
사용자 확정 기록에서: 제목은 「~없던 조선, 질문」(호텔·네비·치과) 또는 「대상·상황, 질문」(늙은궁녀·장한철), 현대 말로 자기 대입(퇴직·네비). 썸네일은 2줄, 한 줄은 아는 대상, 다른 줄은 질문·역설(「궁 나가면 어디서 살지?」「밥값만 내면 잠은 공짜」).

## 제목 후보
1. 학원 없던 조선, 아이들은 서당에서 글을 어떻게 배웠을까 — 「~없던 조선, 질문」+현대 말
2. 천자문 떼면 떡을 돌렸다, 조선 서당 아이들은 하루를 어떻게 보냈을까 — 역설·장면 + 질문(책거리 확인 필요)
3. 회초리 맞으며 외운 천자문, 조선 아이들은 몇 살에 서당에 갔을까 — 신체 감각 + 질문

## 썸네일 후보 (2줄)
A. 조선 아이들 / 서당 가면 뭘 배웠지? — 늙은궁녀 「궁 나가면 어디서 살지?」 구어 질문형
B. 다 외울 때까지 / 종아리 걷어라 — 신체 감각 인용형

## 작업자 추천
제목 1 + 썸네일 A

## 주의·사료 확인
