## 확인 못 한 것 · 쓰지 않은 것 (P11 기록 포함)

- **대기열 hook ‘양반도 부러워했다’**: 학술·1차 근거를 찾지 못함(검색 결과 해당 근거 없음, 견본 영상 미확보). → 같은 강도의 검증된 대비로 교체: ① “평민으로 만들어 주려고 나라가 붙여 준 이름이, 가장 천한 사람의 이름이 됐다”(B1·B7) ② “조선 후기에는 살기 어려운 평민이 오히려 백정이 되기도 했다”(B6, 국가 부담이 없고 도살 이익이 큼). 양반 비교는 쓰지 않음.
- 백정의 복장(패랭이·상투·비녀)·기와집·가마 금지 등 세부 금제: 근거 문헌 미열람 → 쓰지 않고 백과의 범주(혼인·마을·교육·행사·의복·음주 차별)만.
- 갓 착용 허용 청원(1895/1896 엇갈림), 박성춘의 교회 활동: 연도가 출처마다 다름 → 쓰지 않음.
- 이학찬 아들의 구체적 입학 거부 경위: 출처마다 표현 다름 → “자식 교육에서 받은 차별이 계기”까지만.
- 임꺽정(명종 때 백정 출신 도적): 같은 묶음 19번 편 영역 → 언급하지 않음.
- 조선총독부 백정 호구 수(7,538호): 답에 불필요 → 쓰지 않음.

## 낭독 표기 메모

- 재인(才人): “노래·재주를 팔며 떠돌던 사람들”, 화척(禾尺): “소를 잡거나 버들가지 그릇을 엮어 팔며 떠돌던 사람들”로 풀고 이름은 한 번만.
- 유기(柳器)는 ‘놋그릇 유기’와 동음 → 낭독에서 “버들고리”, “버드나무 가지로 엮은 그릇”으로만.
- ‘장적’ → 호적, ‘행장’ → 이동 허가 문서, ‘신량역천’ 용어는 쓰지 않고 뜻으로.
